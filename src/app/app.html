GETTING STARTED

Think in three dimensions.
Draw in two.

Choose Add point (P). Click in one view to define two coordinates, then click in a different view to define the missing coordinate. The gold guide constrains the shared axis.

FRONT X = 2 · Z = 3SIDE Y = 5 · Z = 3POINT (2, 5, 3)

Drag any point to change the two visible coordinates. Its hidden coordinate stays fixed. Use the properties panel for exact values. Edges follow their points.

Layers: choose a fixed X, Y or Z in Explorer and set its value once. Existing and new points on that layer keep this coordinate. New layers start empty; assign an object's layer in Properties, then use the layer icon to activate an object on that layer. Choosing Free 3D releases the constraint.

Multiple points: Shift-click to add or remove points, or drag a box over empty space. Drag any selected point to move the group. Fixed axes constrain the whole group's movement; locked points stay in place. Ctrl+D duplicates editable selected points and the edges between them in place, ready to drag. Ctrl+A selects visible points; Delete removes editable selected points.

Use Reference to add an image to Front, Side or Top. Adjust its width, center and opacity, then choose Place points on image for single-click tracing at the construction depth. Turn off Snap to follow the image freely, or use two-view placement to define depth from another reference.

Use Select all points and Delete selected in Point transform to clear the drawing. Show and unlock all objects and layers to include every point. To reassign part of a drawing, select its points, choose a destination object and click Move to object. Edges between moved points follow; connections to points left behind are removed. The destination layer's fixed coordinate applies.

Right-click a point for Delete, Duplicate, Move to object or Change object's layer. Right-click a selected point to act on the group. Use Choose overlapping point to pick an exact point when projections overlap. Changing an object's layer moves its entire geometry. You can also select its name in Explorer and use Active object → Layer in Properties.

Collections organize objects in Explorer. Drag an object's name onto a collection, or onto Ungrouped to take it out. Use Add collection, then right-click an object and choose Move to collection, or use Active object → Collection in Properties. Right-click a collection to add objects, rename it or remove the collection while keeping its objects. The eye beside a collection hides or shows all its geometry together. Collections organize the scene; layers control fixed coordinates.
